# Учебный проект

## Задание

### 1. Реализация классов

Реализовать в проекте следующие классы согласно диаграмме:

- `Персона`
- `Студент`
- `Преподаватель`
- `Программа`
- `Курс`

Каждый класс должен находиться в отдельном файле и содержать необходимые поля, конструкторы и методы.

### 2. Основной класс проекта

В основном классе проекта:

- создать массивы данных для объектов `Преподаватель`, `Студент`, `Программа`, `Курс`;
- в методе `Main`, используя оператор `switch`, реализовать меню:

  1. Добавить студента
  2. Добавить преподавателя
  3. Добавить программу обучения
  4. Добавить курс*
  0. Выход

- реализовать функционал каждого пункта меню в отдельных методах основного класса.

> \* Реализация добавления курса желательна.

### 3. Класс FileInputOutput

В проект `centerDPO-фамилия` добавить новый класс `FileInputOutput`.

Класс должен содержать статические методы:

- `textFileRead` — чтение данных из текстового файла.
  - Принимает имя файла.
  - Возвращает массив строк.

- `textFileWrite` — запись данных в текстовый файл.
  - Принимает имя файла и массив строк.
  - Возвращает логическое значение.

- `studentsImport` — преобразование данных и запись в массив `students`.
  - Принимает массив объектов `students` и массив строк.
  - Возвращает логическое значение.

- `studentsExport` — преобразование данных и запись в массив строк.
  - Принимает массив объектов `students`.
  - Возвращает массив строк.

Также реализовать аналогичные методы импорта/экспорта для `teachers` и `programs`.
